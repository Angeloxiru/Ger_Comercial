🎯1. Introdução

O Ger Comercial é um sistema completo de análise de dados comerciais desenvolvido especialmente para a Germani Alimentos. Este sistema oferece dashboards interativos que permitem à equipe estratégica comercial tomar decisões baseadas em dados reais.

Objetivo deste Manual

Este manual foi criado para ajudar gestores, diretores e supervisores a:

  • Compreender todas as funcionalidades disponíveis no sistema
  • Utilizar os dashboards de forma eficiente
  • Extrair insights valiosos dos dados
  • Aplicar os resultados na gestão do dia a dia

Principais Benefícios

✅ Benefícios do Sistema:
  • Decisões Baseadas em Dados: Elimine achismos e tome decisões fundamentadas
  • Identificação Rápida de Oportunidades: Detecte clientes inativos e produtos parados antes de perder vendas
  • Análise de Performance: Acompanhe o desempenho individual e coletivo da equipe
  • Visualização Geográfica: Entenda padrões regionais de vendas
  • Exportação de Relatórios: Gere relatórios em Excel, PDF ou envie via WhatsApp
  • Acesso em Qualquer Lugar: Sistema web acessível de qualquer dispositivo

Tecnologia Utilizada

O sistema foi desenvolvido com tecnologias modernas:

  • Frontend: HTML5, CSS3, JavaScript (ES Modules)
  • Banco de Dados: Turso (LibSQL na nuvem)
  • Gráficos: Chart.js para visualizações interativas
  • Mapas: Leaflet.js para geolocalização
  • PWA: Pode ser instalado como aplicativo nativo
  • Shell compartilhado: Todos os dashboards usam a mesma base visual e os mesmos componentes de filtro, período e exportação
💡 Versão do sistema: O número da versão aparece no canto inferior direito da tela inicial (ex: v1.16.1). Informe esse número sempre que abrir um chamado com o TI.

🔐2. Login e Autenticação

Acessando o Sistema

1 Abra o navegador (Chrome, Edge, Firefox ou Safari)

2 Digite o endereço: https://angeloxiru.github.io/Ger_Comercial/

3 O sistema irá redirecionar automaticamente para a tela de login se você não estiver autenticado

Realizando o Login

A tela de login é simples e intuitiva:

1 Digite seu usuário no campo "Usuário"

2 Digite sua senha no campo "Senha"

3 Clique no botão "Entrar" ou pressione Enter

💡 Dica: Você pode pressionar a tecla Enter em qualquer campo para fazer login rapidamente.

Sistema de Permissões

O sistema possui controle de acesso individual: o administrador marca, usuário por usuário, quais dashboards ficam liberados. Não existem perfis fixos: cada conta recebe a combinação de acessos que o gestor definir.

Os acessos que podem ser concedidos são:

Permissão Dashboard liberado
vendas-regiao📍 Vendas por Região
vendas-equipe👥 Vendas por Equipe
analise-produtos📈 Análise de Produtos
categorias-produtos🏷️ Categorias de Produtos
performance-clientes💰 Performance de Clientes
ranking-clientes🏆 Ranking de Clientes
cobranca-semanal🎯 Performance Mensal
produtos-parados🛑 Produtos Parados
clientes-semcompras🗺️ Clientes Sem Compras
gerenciar-usuarios⚙️ Configurações (administradores)
⚠️ Atenção: Dashboards sem permissão aparecem acinzentados na tela inicial, com um cadeado 🔒 no canto. Ao clicar, o sistema avisa que o acesso não está liberado. Se precisar de um dashboard bloqueado, solicite ao administrador.

Limite de Período por Usuário

Para proteger o banco de dados de consultas gigantes, existe um limite de dias em cada filtro de período:

Tipo de conta Período máximo por consulta
Padrão 100 dias
Com "Período Estendido" liberado 366 dias

Se o intervalo escolhido ultrapassar o limite, o sistema exibe um aviso informando quantos dias foram selecionados e não executa a consulta. A liberação do período estendido é feita pelo administrador, na tela de Configurações.

Alterar Senha

Qualquer usuário pode trocar a própria senha, sem depender do TI:

1 Na tela inicial, clique em "Alterar Senha" (ao lado do botão Sair)

2 Informe a senha atual

3 Digite a nova senha e repita na confirmação

4 Clique em "Salvar"

💡 Regras da nova senha:
  • Mínimo de 6 caracteres
  • Nova senha e confirmação precisam ser idênticas
  • A senha atual é conferida antes da troca

Problemas Comuns no Login

Erro: "Usuário ou senha inválidos"

  • Verifique se digitou o usuário e senha corretamente
  • Certifique-se de que a tecla Caps Lock não está ativada
  • Tente copiar e colar suas credenciais

Erro: "Erro ao conectar com o servidor"

  • Verifique sua conexão com a internet
  • Tente recarregar a página (F5)
  • Se o erro persistir, entre em contato com o TI

Logout (Sair do Sistema)

Para sair do sistema com segurança:

1 Clique no botão "🚪 Sair" no canto superior direito

2 Confirme que deseja sair

3 Você será redirecionado para a tela de login

💡 O que o logout faz: Ao sair, o sistema apaga a sessão e todos os dados em cache do navegador (filtros, resultados de consultas e visões carregadas). Isso garante que o próximo usuário do mesmo computador não veja informações da sua conta.

💡 Dica de Navegação: Dashboards que você não tem permissão aparecem acinzentados, com cadeado 🔒, e não abrem. Os cards Repositores e Mapa de Vendas apontam para sistemas externos e abrem em uma nova aba do navegador.

Estrutura Comum dos Dashboards

Todos os dashboards de dados seguem a mesma estrutura:

  1. Cabeçalho: Título do dashboard, botão "← Voltar" e indicador 🕒 atualizado há…, que mostra quando os dados na tela foram buscados
  2. ⭐ Visões salvas: Barra para salvar e recarregar combinações de filtros
  3. Seção de Filtros: Período com atalhos rápidos + filtros específicos do dashboard
  4. Botões de ação: "🧹 Limpar Filtros" e os botões que executam a consulta (variam por dashboard: Itens, Clientes, Resumido, Detalhado, Atualizar…)
  5. KPIs (Indicadores): Resumo dos principais números, com opção de comparativo "vs Anterior" / "vs Ano"
  6. Gráficos: Visualizações interativas dos dados
  7. Tabela de Dados: Detalhamento completo com paginação
  8. Botões de Exportação: Excel, PDF e, em alguns dashboards, WhatsApp
⚠️ Os dados não aparecem sozinhos: Na maioria dos dashboards a tela inicia vazia. É preciso escolher os filtros e clicar no botão de consulta (Itens, Clientes, Resumido, Detalhado, Atualizar ou Buscar) para carregar os dados.

Dicas de Usabilidade

✅ Boas Práticas:
  • Sempre aplique os filtros antes de analisar os dados
  • Use os atalhos de período (30 dias, Mês atual, Mês anterior, Trimestre, Ano) em vez de digitar datas
  • Salve como "visão" as combinações de filtros que você usa toda semana
  • Utilize os botões de exportação para compartilhar relatórios
  • Observe os KPIs para ter uma visão rápida dos números
  • Passe o mouse sobre gráficos para ver detalhes
  • Copie o endereço da página para compartilhar a análise com os mesmos filtros

📍4. Dashboard: Vendas por Região

Objetivo

Analisar vendas segmentadas por localização geográfica (rota, sub-rota e cidade), identificando regiões de alto desempenho, oportunidades de crescimento e sobreposição de roteiros.

Como Utilizar

Passo 1: Aplicar Filtros

O dashboard usa filtros em cascata que se relacionam entre si:

1 Período: Escolha um atalho (30 dias, Mês atual, Mês anterior, Trimestre, Ano) ou digite as datas de início e fim

2 🛣️ Rota: Escolha a rota (atualiza automaticamente SubRota e Cidade)

3 🗺️ SubRota: Refine por sub-rota específica

4 🏙️ Cidade: Escolha uma ou mais cidades

💡 Filtros Inteligentes: Todos os campos de seleção possuem busca digitável: comece a digitar e a lista é filtrada automaticamente. Os filtros aceitam seleção múltipla (segure Ctrl para marcar mais de uma opção).

Passo 2: Escolher o Modo de Consulta

Os três botões azuis executam a consulta, cada um com um recorte diferente:

Botão O que mostra Quando usar
📦 Itens Análise por produto (SKU) na região filtrada Para entender quais produtos mais vendem na região
👥 Clientes Análise consolidada por cliente Para identificar os maiores clientes da região
📍 Roteiros Sub-rotas atendidas por mais de um representante Para detectar sobreposição de roteiros e conflito de atendimento

Passo 3: Analisar KPIs

Nos modos Itens e Clientes:

  • Valor Total (R$): Faturamento do período filtrado
  • Quantidade: Unidades vendidas
  • Peso Total (kg): Volume em peso
  • Registros: Linhas retornadas na consulta

No modo Roteiros os indicadores mudam:

  • Sub-Rotas Compartilhadas: Quantas sub-rotas têm mais de um representante atuando
  • Reps Envolvidos: Quantidade de representantes nessa situação
  • Total Sub-Rotas: Base de comparação
  • Valor Total: Faturamento envolvido

Passo 4: Interpretar os Gráficos

  1. Top 10 Produtos / Top 10 Clientes: Barras com os 10 maiores por valor (o título muda conforme o modo)
  2. Vendas por Cidade: Participação de cada cidade no faturamento
  3. Evolução Mensal (Últimos 12 Meses): Tendência histórica da região filtrada
💡 Interação com Gráficos: Passe o mouse sobre as barras ou fatias para ver os valores exatos e percentuais.

Passo 5: Explorar a Tabela Detalhada

A tabela mostra os dados filtrados com código, descrição/nome, quantidade, valor e peso. Use a paginação na parte inferior para navegar pelos resultados.

Casos de Uso Práticos

✅ Caso 1: Identificar Produtos Mais Vendidos por Região

Situação: Preciso saber quais produtos têm melhor aceitação em uma rota.

Ação:

  1. Escolha o período
  2. Filtre pela Rota desejada
  3. Clique em 📦 Itens
  4. Analise o gráfico "Top 10 Produtos"

Resultado: Você verá os produtos campeões de venda na região e poderá replicar essa estratégia em outras áreas.

✅ Caso 2: Comparar Desempenho entre Cidades

Ação:

  1. Aplique o período sem escolher cidade específica
  2. Clique em 👥 Clientes
  3. Observe o gráfico "Vendas por Cidade"
  4. Identifique as cidades com menor participação

Resultado: Detecta cidades com baixo desempenho que precisam de atenção da equipe comercial.

✅ Caso 3: Descobrir Sobreposição de Roteiros

Situação: Suspeita de que dois representantes atendem a mesma sub-rota.

Ação:

  1. Selecione o período (sugestão: últimos 90 dias)
  2. Clique em 📍 Roteiros
  3. Veja as sub-rotas com mais de um representante e o valor envolvido

Aplicação Gerencial: Redefinir a divisão de roteiros, evitar visita duplicada e reduzir custo de deslocamento.

Exportação de Dados

  • 📊 Excel: Arquivo .xlsx com todos os dados filtrados
  • 📄 PDF: Relatório formatado pronto para impressão
⚠️ Importante: Os nomes dos arquivos exportados incluem automaticamente o modo selecionado e o período filtrado. Exemplo: vendas_regiao_itens_2026-08-01_2026-08-31.xlsx

👥5. Dashboard: Vendas por Equipe

Objetivo

Analisar a performance individual e coletiva dos vendedores, separando venda faturada de bonificação e permitindo identificar top performers e oportunidades de melhoria.

Como Utilizar

Aplicar Filtros

1 📅 Período: Use os atalhos ou informe início e fim

2 👔 Supervisor: Escolha um supervisor (opcional)

3 👤 Representante: Filtre por vendedor específico (a lista respeita o supervisor selecionado)

4 🏙️ Cidade: Refine por localização (opcional)

5 🎁 Bonificação: Escolha se quer ver tudo, apenas venda normal ou apenas bonificação

Modos de Consulta

  • 📦 Itens: Mostra os produtos vendidos por cada representante
  • 👥 Clientes: Mostra os clientes atendidos por cada representante

Indicadores Principais (KPIs)

KPI Significado
Valor Total Faturamento de todos os vendedores filtrados no período
Quantidade Soma de unidades vendidas
Peso Total Volume total em kg
Total Registros Linhas retornadas na consulta
Bonificação Valor entregue como bonificação no período
% Bonificação Quanto a bonificação representa do total, indicador de custo comercial
💡 Comparativo de período: Acima dos KPIs existe o toggle "📊 vs Anterior" e "📊 vs Ano". Ativando um deles, cada indicador ganha a variação percentual contra o período anterior de mesmo tamanho ou contra o mesmo período do ano passado (ex: ▲ +15,2%).
💡 Atalho para Produtos Parados: Ao selecionar um representante, aparece um botão que leva direto ao dashboard Produtos Parados já filtrado por ele. Use para investigar quedas de faturamento.

Casos de Uso Práticos

✅ Caso 1: Identificar Melhor Vendedor do Mês

Ação:

  1. Escolha o atalho "Mês anterior"
  2. Não selecione representante específico
  3. Clique em 👥 Clientes ou 📦 Itens
  4. Observe o gráfico com os maiores representantes

Aplicação Gerencial: Use para premiações, reconhecimento público e definição de metas baseadas no melhor desempenho.

✅ Caso 2: Controlar o Custo de Bonificação

Situação: O faturamento cresceu, mas a margem caiu.

Ação:

  1. Selecione o período e o supervisor
  2. Observe o KPI % Bonificação
  3. Ative o comparativo "vs Anterior" para ver se o percentual subiu
  4. Filtre por Bonificação para listar apenas o que foi bonificado

Aplicação Gerencial: Identifique representantes que estão comprando volume com bonificação e ajuste a política comercial.

✅ Caso 3: Comparar Performance de uma Equipe

Ação:

  1. Selecione o Supervisor da equipe
  2. Deixe Representante sem seleção
  3. Analise a distribuição entre os membros

Aplicação Gerencial: Identifique vendedores que precisam de treinamento ou coaching, comparando com a média da equipe.

💡 Dica para Supervisores: Faça análises semanais para acompanhar a evolução individual de cada representante e dar feedbacks construtivos. Salve o filtro da sua equipe como visão para não refazer a seleção toda semana.

📈6. Dashboard: Análise de Produtos

Objetivo

Descobrir quem compra cada produto. Você parte de um produto, família ou origem e o dashboard responde quais clientes e cidades sustentam aquela venda.

Filtros Disponíveis

  • 📅 Período: Atalhos rápidos (30 dias, Mês atual, Mês anterior, Trimestre, Ano) ou datas manuais
  • 🏭 Origem: Produto fabricado vs revenda
  • 📂 Família: Categoria de produtos
  • 📦 Produto: SKU específico, com busca digitável

Depois de escolher os filtros, clique em 🔄 Atualizar Dados.

O que o Dashboard Entrega

Elemento Conteúdo
KPIs Valor Total, Quantidade, Peso Total e Total de Registros
Tabela Cliente, Razão Social, Cidade, Qtde, Valor (R$) e Peso (kg)
🏆 Top 10 Clientes Maiores compradores do produto/família filtrado
🗺️ Vendas por Cidade (Top 5) Onde esse produto tem mais saída
💡 Comparativo e exportação: O toggle "📊 vs Anterior" / "📊 vs Ano" também está disponível aqui. A exportação deste dashboard é em Excel.

Casos de Uso Práticos

✅ Caso 1: Recuperar um Produto que Parou de Vender

Situação: O dashboard Produtos Parados apontou um item crítico.

Ação:

  1. No Produtos Parados, clique na linha do produto e o sistema abre a Análise de Produtos já filtrada por ele, nos últimos 90 dias
  2. Veja no "Top 10 Clientes" quem ainda compra
  3. Compare com a lista de clientes que compravam antes

Aplicação Gerencial: Aborde primeiro os clientes que já conhecem o produto, pois a chance de retomada é muito maior do que prospectar do zero.

✅ Caso 2: Avaliar Mix Fabricado vs Revenda

Ação:

  1. Filtre apenas o período
  2. Consulte com Origem = fabricado e anote o Valor Total
  3. Repita com Origem = revenda
  4. Compare os dois números

Aplicação Gerencial: Se a revenda domina, pode ser necessário incentivar a linha própria. Se o produto fabricado está parado, investigue qualidade, disponibilidade ou precificação.

✅ Caso 3: Lançamento de Produto

Ação:

  1. Filtre pelo produto lançado
  2. Use o período desde o lançamento
  3. Observe a distribuição por cidade

Aplicação Gerencial: Identifique as regiões que ainda não compraram o lançamento e direcione a ação da equipe.

🏷️7. Dashboard: Categorias de Produtos

Objetivo

Comparar o desempenho das categorias estratégicas da Germani em peso, valor e preço médio por quilo (R$/KG), acompanhando a evolução semanal de cada uma.

Categorias Analisadas

  • 🍪 Biscoitos
  • 🌾 Cereais
  • 🍝 Massas
  • 🍜 Instantâneo
  • ⭐ Catterino

Todas vêm marcadas por padrão. Desmarque as que não quiser comparar.

Filtros Disponíveis

  • 📅 Período: Atalhos rápidos ou datas manuais
  • 👔 Supervisor e 👤 Representante: Recorte por equipe
  • 🏷️ Categorias: Caixas de seleção das cinco categorias
  • 🏢 Cód. Grupo de Cliente: Digite um ou mais códigos separados por vírgula (ex: 101, 202)

Modos de Consulta

Botão O que mostra
📊 Resumido Totais consolidados por categoria
📋 Detalhado Abertura maior dentro de cada categoria

Indicadores (KPIs)

  • ⚖️ Peso Total: Volume em kg no período
  • 💰 Valor Total: Faturamento no período
  • 📊 R$/KG Médio: Preço médio por quilo, principal indicador de valor agregado
  • 🏷️ Categorias Ativas: Quantas categorias tiveram venda

Tabela e Gráficos

A tabela "Comparativo por Categoria" traz: Categoria, Peso (kg), Valor (R$), R$/KG, % Peso e % Valor. Ao lado ficam quatro gráficos:

  1. 🍩 Participação por Valor: Fatia de cada categoria no faturamento
  2. 📈 Evolução Semanal - Valor (R$)
  3. ⚖️ Evolução Semanal - Peso (kg)
  4. 📉 Evolução Semanal - R$/KG
💡 Por que o R$/KG importa: Duas categorias podem faturar o mesmo com volumes muito diferentes. O R$/KG mostra qual delas entrega mais receita por quilo produzido e transportado. É o indicador que liga comercial, produção e logística.

Casos de Uso Práticos

✅ Caso 1: Detectar Queda de Preço Médio

Ação:

  1. Selecione o trimestre atual
  2. Marque todas as categorias e clique em Resumido
  3. Observe o gráfico "Evolução Semanal - R$/KG"

Interpretação: Se o peso sobe e o R$/KG cai, a equipe está ganhando volume dando desconto. Confirme no dashboard Vendas por Equipe se a bonificação também aumentou.

✅ Caso 2: Comparar Equipes pelo Mix de Categoria

Ação:

  1. Selecione um supervisor e consulte
  2. Anote o % Valor de cada categoria
  3. Repita para outro supervisor

Aplicação Gerencial: Equipes muito concentradas em uma única categoria precisam de treinamento no restante do portfólio.

Exportação

Disponível em 📊 Excel e 📄 PDF, respeitando os filtros e as categorias marcadas.

💰8. Dashboard: Performance de Clientes

Objetivo

Analisar a saúde da carteira de clientes: quanto cada grupo e cada cliente comprou, com que ticket médio e quais produtos sustentam essa venda.

Filtros

  • 📅 Período: Atalhos rápidos ou datas manuais
  • 🔍 Código do Grupo de Cliente: Digite o código quando souber exatamente qual grupo quer
  • 👥 Grupo: Seleção do grupo de clientes na lista
  • 🏢 Cliente: Cliente específico, com busca digitável

Modos de Consulta

Botão O que mostra Quando usar
📊 Resumido Totais consolidados por cliente/grupo Visão gerencial rápida
📋 Detalhado Abertura por produto dentro de cada cliente Preparar visita ou negociação específica

KPIs Principais

Indicador Cálculo Uso Gerencial
Valor Total Soma do faturamento no período Acompanhar meta de faturamento
Quantidade Unidades vendidas Avaliar volume
Peso Total Volume em kg Planejamento logístico
Total Registros Linhas retornadas Dimensionar a consulta
Ticket Médio Valor Total ÷ clientes Avaliar poder de compra médio
Clientes Ativos Clientes únicos que compraram Acompanhar crescimento da base

Visualizações

  1. Tabela paginada: Resultados ordenados por valor
  2. 🏆 Top 10 Produtos por Quantidade: O que esses clientes mais levam
  3. 👥 Top 5 Clientes por Valor: Quem mais pesa no faturamento filtrado
💡 Este dashboard é o destino do drill-down: Ao clicar em uma linha do Ranking de Clientes, o sistema abre a Performance de Clientes já filtrada por aquele cliente ou grupo, em modo Detalhado e com o mesmo período. Não é preciso refazer os filtros.

Casos de Uso Práticos

✅ Caso 1: Preparar uma Visita Comercial

Ação:

  1. Filtre pelo cliente que será visitado
  2. Use o período dos últimos 90 dias
  3. Clique em 📋 Detalhado
  4. Veja quais produtos ele compra e quais deixou de comprar

🛑11. Dashboard: Produtos Parados

Objetivo

Identificar produtos que PARARAM de ser vendidos por representantes, detectando perda de clientes antes que seja tarde.

⚠️ Dashboard Crítico: Este é um dos dashboards mais importantes para prevenção de perdas. Use semanalmente!

Filtros

  • Supervisor: Recorte por equipe
  • Representante: Análise individual
  • Nível de Risco: Extremo (6+ sem), Muito Alto (5 sem), Alto (4 sem), Moderado (3 sem), Baixo (2 sem) ou Mínimo (1 sem)

Clique em 🔄 Atualizar para carregar a lista.

Indicadores (KPIs)

  • Total de Produtos Parados: Quantidade de combinações representante + produto sem venda
  • Valor Total em Risco: Faturamento que deixou de acontecer
  • Representantes Afetados: Quantos vendedores estão na lista
  • Média de Semanas Parado: Gravidade média da situação

Lógica de Detecção

O sistema identifica produtos parados através de:

  1. Calcula a última venda de cada representante + produto
  2. Conta quantas semanas se passaram desde então
  3. Se passou 1+ semana = PRODUTO PARADO
  4. Classifica em 6 níveis de risco

Classificação de Risco

Nível Semanas Parado Cor Ação Recomendada
⚫ EXTREMO 6+ Bordô EMERGENCIAL! Cliente pode estar perdido
🔴 MUITO ALTO 5 Vermelho URGENTE! Contato imediato
🟠 ALTO 4 Laranja IMPORTANTE! Agendar visita
🟡 MODERADO 3 Amarelo ATENÇÃO! Incluir na próxima rota
🟢 BAIXO 2 Verde OBSERVAR! Monitorar na semana
🔵 MÍNIMO 1 Azul NORMAL! Acompanhamento padrão

Informações da Tabela

Para cada produto parado, o sistema mostra:

  • Nível de Risco: Código de cores
  • Supervisor e Representante: Responsáveis
  • Produto: Código e descrição
  • Último Cliente: NOVO! Quem comprou pela última vez
  • Última Venda: Data da última transação
  • Semanas Parado: Tempo sem vender
  • Valor Médio: Quanto faturava com esse produto

Recursos Especiais

📱 Botão WhatsApp

Funcionalidade exclusiva deste dashboard:

1 Clique no botão "📱 WhatsApp"

2 Sistema busca automaticamente o telefone do representante

3 Abre WhatsApp Web com mensagem formatada contendo:

  • Data do relatório
  • Resumo geral (total de produtos parados, valor em risco)
  • TOP 5 produtos críticos com nome do último cliente
💡 A mensagem já vem pronta: O WhatsApp envia data do relatório, resumo geral e o nome do cliente que comprou pela última vez em cada produto crítico, facilitando a abordagem comercial.

🔎 Clique na linha para investigar

Cada linha da tabela é clicável. Ao clicar em um produto, o sistema abre o dashboard Análise de Produtos já filtrado por aquele item, com os últimos 90 dias, mostrando quais clientes ainda o compram.

📊 Gráficos

  • Top produtos parados: Itens que mais aparecem na lista
  • Distribuição por nível de risco: Quantos produtos em cada faixa

📄 Exportação

Este dashboard exporta em PDF e envia resumo por WhatsApp. Para trabalhar os dados em planilha, use o drill-down para a Análise de Produtos, que exporta em Excel.

Casos de Uso Práticos

✅ Caso: Recuperar Cliente Antes de Perdê-lo

Situação: Representante João sempre vendia Produto X para Cliente ABC, mas parou há 4 semanas.

Ação Imediata:

  1. Filtrar por Representante "João"
  2. Identificar Produto X na lista (risco 🟠 ALTO)
  3. Ver que último cliente foi "ABC Comércio"
  4. Clicar em WhatsApp e enviar mensagem

Script Sugerido para o Representante:

"Olá João! Notei que o cliente ABC Comércio não compra Produto X há 4 semanas. Eles costumavam comprar regularmente. Houve algum problema? Podemos agendar uma visita para entender o que aconteceu?"

Resultado Esperado:

  • Descobre que concorrente ofereceu preço melhor → Ação: criar promoção
  • Descobre que produto teve problema de qualidade → Ação: trocar lote
  • Descobre que cliente simplesmente esqueceu → Ação: reativar pedido
✅ Caso: Gestão Preventiva Semanal

Rotina Recomendada: Toda segunda-feira de manhã:

  1. Acessar dashboard Produtos Parados
  2. Filtrar por nível de risco "EXTREMO" e "MUITO ALTO"
  3. Exportar PDF com a lista completa
  4. Reunir supervisores e distribuir ações
  5. Enviar WhatsApp para cada representante com seus produtos críticos
  6. Acompanhar na sexta-feira quantos foram recuperados

Impacto Esperado: Redução de 50-70% na perda de clientes por "esquecimento" ou falta de acompanhamento.

Sistema de Cache

Para reduzir o tempo de espera, o sistema guarda o resultado das consultas por um tempo. Esse tempo é calculado conforme o período analisado:

Período consultado Tempo de cache Por quê
Fechado (mês ou período já encerrado) 24 horas O dado não muda mais
Em curso (inclui hoje) 10 minutos Ainda entram notas novas
💡 Cache de filtros: As listas de filtros e a última seleção ficam guardadas por cerca de 30 minutos. Ao voltar para o mesmo dashboard nesse intervalo, tudo já vem preenchido.
⚠️ Quando o número parecer errado: Confira o indicador "🕒 atualizado há…" e a data de Último Faturamento na tela inicial. Se ainda houver divergência, faça logout e login novamente, pois a saída limpa todo o cache do navegador.

Cenários de Tomada de Decisão

Cenário 1: Queda de Vendas em Região Específica

Sintoma: Faturamento da Região Sul caiu 30% vs mês anterior.

Diagnóstico usando o sistema:

  1. Vendas por Região: Confirmar queda e identificar cidades mais afetadas
  2. Vendas por Equipe: Verificar se é problema de um representante específico ou geral
  3. Clientes Sem Compras: Ver quantos clientes pararam de comprar na região
  4. Produtos Parados: Identificar se há produtos específicos afetados

Possíveis Causas:

  • Representante doente/afastado → Redistribuir rota
  • Cliente grande inadimplente → Negociar pagamento
  • Concorrente agressivo → Criar promoção
  • Problema de qualidade em produto → Investigar produção
Cenário 2: Concentração Excessiva em Poucos Clientes

Sintoma: Ranking de Clientes mostra que Top 5 = 85% do faturamento.

Risco: Perder 1 cliente VIP pode quebrar a empresa!

Estratégia de Mitigação:

  1. Curto Prazo:
    • Criar programa de fidelidade para Top 5
    • Visitas semanais da diretoria aos clientes VIP
    • Condições comerciais especiais
  2. Médio Prazo:
    • Usar "Clientes Sem Compras" para reativar inativos
    • Usar "Performance de Clientes" para identificar clientes médios com potencial de crescimento
    • Investir em prospecção de novos clientes
  3. Meta: Reduzir concentração Top 5 para 60% em 6 meses
Cenário 3: Produto com Alta Margem Parando de Vender

Sintoma: Dashboard Produtos Parados mostra Produto Premium (alta margem) há 6 semanas parado.

Impacto: Margem de lucro está caindo mesmo com volume constante.

Ação Imediata:

  1. Identificar qual cliente comprava esse produto (coluna "Último Cliente")
  2. Ligar HOJE para o cliente e entender motivo
  3. Oferecer amostra grátis ou condição especial
  4. Agendar visita presencial urgente
  5. Monitorar semanalmente até recuperar
